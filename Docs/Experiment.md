## 1. 実験概要

### 1.1 研究目的

LLM駆動ABMによる避難シミュレーションが、以下の点を達成できるかを検証する：

1. **リサーチクエスチョン1**: LLMエージェントは現実的な避難行動を再現できるか
2. **リサーチクエスチョン2**: ペルソナにより有意な行動多様性が生まれるか
3. **リサーチクエスチョン3**: RAGは地域特性に適応した意思決定を支援するか

### 1.2 実験構成

| 実験 | 目的 | 主要指標 |
|------|------|---------|
| 実験1 | 基本性能の検証 | 避難完了率、行動多様性 |
| 実験2 | 人間行動モデリングの検証 | 認知バイアスの影響、社会的相互作用 |
| 実験3 | 情報提供戦略の検証 | 情報条件による行動変化 |

### 1.3 共通設定

| パラメータ | 値 | 備考 |
|-----------|-----|------|
| エージェント数 | 500体 | 計算コストとバランスを考慮 |
| 対象地域 | いわき市平豊間・平薄磯地区 | PLATEAU対応地域 |
| 発災時刻 | 14:46（平日昼間） | 東日本大震災を参考 |
| 津波到達予測 | 発災後25分 | いわき市沿岸部の実績 |
| シミュレーション時間 | 30分（1800秒） | 津波到達まで |
| 試行回数 | 各条件N=10 | 統計的有意性確保 |

## 3. 実験1：基本性能の検証

### 3.1 目的

LLMエージェントとルールベースエージェントを比較し、LLMエージェントの基本性能と行動の多様性を検証する。

### 3.2 実験条件

| 条件 | エージェントタイプ | 説明 |
|------|------------------|------|
| 条件A | LLMエージェント | LLMによる意思決定 |
| 条件B | ルールベースエージェント | 固定ルールによる意思決定 |

#### ルールベースエージェントの行動ルール（Level 2実装済み）

現在の実装では以下の優先度順で行動を選択する：

```text
優先度1: 津波警報時のみ緊急避難
  Jアラート OR 行政無線 OR 消防団呼びかけ → EVACUATE（最寄り避難所）
  ※地震（震度）だけでは動かない

優先度2: 家族対応（津波警報がない場合）
  シーン内未合流家族 AND 距離500m以内 → SEARCH_FAMILY（子供優先）
  シーン外家族 AND 未連絡 → CONTACT（1回限り）

優先度3: 待機
  津波警報なし → STAY
  ※待機時間上限（600秒=10分）を超えた場合のみEVACUATE

デフォルト: STAY
```

**対応アクション**: EVACUATE, STAY, SEARCH_FAMILY, CONTACT
**非対応アクション**: FOLLOW, TALK（効率的な避難には不要と判断）

詳細は [RuleBasedAgent.md](Module/RuleBasedAgent.md) を参照

### 3.3 実行手順

#### Phase 1: LLMエージェント実験（条件A）

1. ExperimentConfigで以下を設定：
   - `SelectedAgentType = LLM`
   - `NumberOfTrials = 10`
   - `ExperimentName = "exp1_llm"`
   - `AutoStartOnPlay = true`
2. シミュレーションを実行（10回自動で繰り返し）
3. `Logs/experiment_results/` に結果が自動保存される

#### Phase 2: ルールベースエージェント実験（条件B）

1. ExperimentConfigで以下を設定：
   - `SelectedAgentType = RuleBased`
   - `NumberOfTrials = 10`
   - `ExperimentName = "exp1_rule"`
   - `AutoStartOnPlay = true`
2. シミュレーションを実行（10回自動で繰り返し）
3. `Logs/experiment_results/` に結果が自動保存される

### 3.4 測定指標

| 指標 | 計算方法 | 期待される結果 |
|------|---------|---------------|
| 避難完了率 | 避難所到達者数 / 総エージェント数 | LLM: 85-95%, Rule: 95-100% |
| 平均避難時間 | 発災〜避難所到達の平均 | LLM > Rule（家族探索等で遅延） |
| 行動選択分布 | 各行動タイプの選択割合 | LLM: 6種全て使用、Rule: 主にEVACUATE（90%以上） |
| 避難所選択分布 | 各避難所の選択者数 | LLM: 分散、Rule: 最寄り集中 |

**注**: ルールベースエージェントもLevel 2ではSEARCH_FAMILY/CONTACTを選択するが、津波警報後は即座にEVACUATEに切り替わるため、最終的な行動分布はEVACUATEが大多数を占める

### 3.5 確認すべきポイント

1. **行動の多様性**
   - LLMエージェントが STAY, SEARCH_FAMILY, TALK, CONTACT, FOLLOW を選択するか
   - ルールベースは EVACUATE, STAY, SEARCH_FAMILY, CONTACTの4種を使用するが、津波警報後はEVACUATEが大多数

2. **経路選択の違い**
   - LLMエージェントが最短経路以外を選択するケースがあるか
   - 「人間的な」判断（混雑回避、安全経路優先）が観察されるか
   - ルールベースは常に最寄りの避難所を選択

3. **避難時間分布**
   - LLMエージェントの避難時間に大きな分散があるか
   - ルールベースは津波警報受信タイミングに依存した分布

4. **家族対応の違い**
   - LLMエージェントは状況判断でSEARCH_FAMILYを継続する可能性
   - ルールベースは津波警報で即座にEVACUATEに切り替え

### 3.6 期待される結果

- **LLMエージェント**: 避難完了率はやや低下するが、行動の多様性が大幅に向上
- **ルールベースエージェント**: 高効率だが画一的な行動
- **結論**: LLMエージェントは「人間らしい」多様な行動を再現できる

## 4. 実験2：人間行動モデリングの検証

### 4.1 目的

LLMエージェントが人間らしい避難行動を再現できるかを、個人特性・認知バイアス・社会的相互作用の3観点から検証する。

### 4.2 実験2-1：個人特性による行動多様性

#### 実験条件

同一シナリオで異なるペルソナを持つエージェントの行動差異を分析する。

| 属性グループ | ペルソナ特性 | 期待される行動傾向 |
|-------------|-------------|-------------------|
| 高齢者（65歳以上） | 移動速度低、過去経験あり | 避難開始遅延、経路選択慎重 |
| 子育て世帯 | 家族構成あり | SEARCH_FAMILY高頻度 |
| 単身若年層 | 移動速度高 | 早期避難、最短経路選択 |
| 消防団員 | 他者支援優先 | TALK高頻度、遅延避難 |

#### 測定指標

- 避難開始時刻と年齢の相関
- SEARCH_FAMILY選択率と家族構成の相関
- TALK選択率と職業の相関

#### 期待される結果

- 年齢と避難開始時刻に正の相関（高齢ほど遅延）
- 家族構成とSEARCH_FAMILY選択率に強い正の相関
- 職業（消防団員等）とTALK選択率に正の相関

### 4.3 実験2-2：認知バイアスの影響

#### 実験条件

| 条件 | バイアス設定 | ペルソナへの反映 |
|------|-------------|----------------|
| 条件1 | ベースライン（なし） | 合理的判断を促すプロンプト |
| 条件2 | 正常性バイアス | 「過去の災害で大丈夫だった」記述追加 |
| 条件3 | 同調バイアス | 「周囲の行動に従う傾向」記述追加 |
| 条件4 | 複合バイアス | 条件2+3の両方 |

#### 測定指標

| 指標 | 条件1 | 条件2 | 条件3 | 条件4 |
|------|-------|-------|-------|-------|
| 平均避難開始時刻 | 基準 | 遅延予測 | やや遅延 | 最も遅延 |
| 避難完了率 | 最高 | 低下 | やや低下 | 最低 |
| STAY選択率 | 最低 | 上昇 | - | 上昇 |
| FOLLOW選択率 | 基準 | - | 上昇 | 上昇 |

#### 実行手順

1. 各条件のペルソナCSVを準備（mental_stateフィールドを変更）
2. 各条件で10試行ずつ実行
3. 避難開始時刻、行動選択を記録

#### 期待される結果

- **条件2（正常性バイアス）**: 避難開始が平均3-5分遅延、STAY選択率上昇
- **条件3（同調バイアス）**: 集団的な遅延発生、FOLLOW選択率上昇
- **条件4（複合）**: 最も遅延、避難完了率が顕著に低下

### 4.4 実験2-3：社会的相互作用の影響

#### 実験条件

| 条件 | コミュニケーション | 家族設定 |
|------|-------------------|---------|
| 条件1 | 無効 | なし |
| 条件2 | 有効 | なし |
| 条件3 | 有効 | あり |

#### 測定指標

- TALK発生回数
- CONTACT発生回数
- 家族合流成功率（条件3のみ）
- 同調行動（FOLLOW）発生率
- 平均避難時間

#### 期待される結果

- **条件1→条件2**: 情報共有により避難効率向上
- **条件2→条件3**: 家族探索により避難時間増加、但し家族合流成功
- 情報共有による「正しい避難所選択」の増加

## 5. 実験3：情報提供戦略の検証

### 5.1 目的

**想定を超える災害において、行政はどのような情報を提供すれば住民の適切な避難行動を促進できるか**を検証する。

#### 背景

東日本大震災では、以下の問題が明らかになった：

1. **初報の過小評価**: 当初の津波警報「3m」が逃げ遅れの一因となった
2. **指定避難所の限界**: 想定（3〜5m）を超える津波（8.5m以上）により、指定避難所自体が浸水・流失
3. **事前知識の上書き困難**: 住民は「津波＝指定避難所へ」という平時の知識に従い、状況変化への対応が遅れた

本実験では、**「情報の具体性」と「表現の強度（切迫感）」**の2軸で行政の情報提供戦略を検証する。

### 5.2 実験設計：2軸アプローチ

#### 軸1: 情報の具体性（Specificity）

| レベル | 内容 | 例 |
|--------|------|-----|
| **Low** | 津波高さの数値のみ | 「予想高さ3m」→「6m以上に更新」 |
| **High** | 高さ＋具体的避難先指示 | 「海抜20m以上の高台へ」「○○小学校では不十分、裏山へ」 |

#### 軸2: 表現の強度/切迫感（Urgency）

| レベル | 内容 | 例 |
|--------|------|-----|
| **Neutral** | 事務的・定型文 | 「大津波警報が発表されました。避難してください」 |
| **High** | 感情的・切迫的 | 「東日本大震災クラスです！今すぐ高台へ！命を守る行動を！」 |

#### 2×2実験条件マトリクス

|  | **切迫感: 低（Neutral）** | **切迫感: 高（High）** |
|--|--------------------------|----------------------|
| **具体性: 低（Low）** | **条件A**: 標準警報のみ | **条件B**: 強い警告表現 |
| **具体性: 高（High）** | **条件C**: 詳細な避難先指示 | **条件D**: 詳細＋強い切迫感 |

### 5.3 共通要素（全条件）

住民エージェントは以下の**事前知識**を持っている：
- 「津波が来たら○○小学校（指定避難所）へ避難する」というハザードマップに基づく知識
- 指定避難所の位置認識

```
[0分] 地震発生（震度7）
      → 全エージェントが揺れを感知

[2分] 大津波警報発表（全条件共通）
      → J-ALERT・行政無線で配信
      → 当初予想高さ: 3m
```

### 5.4 各条件の詳細

#### 条件A: 標準警報のみ（具体性:低 × 切迫感:低）

**行政の姿勢**: 気象庁発表をそのまま伝達（定型的対応）

```
[2分] 「大津波警報が発表されました。予想高さ3メートル。
      高台または指定避難所に避難してください」

[8分] 「津波の予想高さが6メートル以上に更新されました。
      引き続き避難を継続してください」
```

**検証ポイント**:
- 3m→6mの数値更新だけで行動変容が起きるか
- 指定避難所（海抜20-30m）への避難で十分と判断するか

#### 条件B: 強い警告表現（具体性:低 × 切迫感:高）

**行政の姿勢**: 危機感を強調（NHKアナウンサー調）

```
[2分] 「【緊急】大津波警報！予想高さ3メートル！
      今すぐ高台に避難してください！」

[8分] 「【緊急】津波予想が6メートル以上に更新！
      想定を超える津波のおそれ！
      命を守る行動を取ってください！今すぐ逃げて！」
```

**検証ポイント**:
- 切迫した表現が正常性バイアスを解除するか
- パニック的行動（無計画な移動）が発生するか
- 避難開始タイミングが早まるか

#### 条件C: 詳細な避難先指示（具体性:高 × 切迫感:低）

**行政の姿勢**: 具体的な避難先を案内（情報提供重視）

```
[2分] 「大津波警報が発表されました。予想高さ3メートル。
      指定避難所に避難してください」

[8分] 「津波の予想高さが6メートル以上に更新されました。
      江名公民館（海抜20m）では高さが不十分な可能性があります。
      豊間中学校（海抜30m）、諏訪神社（海抜35m）、
      または中田山の高台（海抜40m以上）への避難を推奨します」
```

**検証ポイント**:
- 具体的な高度情報が避難先選択を変えるか
- 「○○では不十分」という否定情報の効果
- 非指定避難所（寺社、高台）への避難が増えるか

#### 条件D: 詳細＋強い切迫感（具体性:高 × 切迫感:高）

**行政の姿勢**: 全力で避難を促す（最大限の情報提供）

```
[2分] 「【緊急】大津波警報！予想高さ3メートル！
      今すぐ高台に避難してください！」

[8分] 「【緊急】想定を大幅に超える津波のおそれ！
      予想高さ8メートル以上！東日本大震災クラスです！

      江名公民館・江名小学校では危険です！
      今すぐ豊間中学校（海抜30m）、諏訪神社（海抜35m）、
      中田山の高台へ避難してください！

      命を守ってください！走って！」
```

**検証ポイント**:
- 具体性と切迫感の相乗効果
- 最も高い避難完了率・生存率が達成されるか
- 情報過多による混乱は発生するか

### 5.5 津波シナリオ

| 時刻 | イベント | 予想高さ |
|------|---------|---------|
| 0分 | 地震発生（震度7） | - |
| 2分 | 大津波警報発表 | 3m |
| 8分 | 警報更新 | 6m以上（条件により8m以上） |
| 25分 | 津波到達 | 実際の高さ: 8m |

### 5.6 生存判定

津波到達時（25分後）にエージェントの生存を判定する。

#### 判定基準

**安全ライン**: 現在位置の標高 ≥ 津波高さ × 2

| 状況 | 判定式 |
|------|--------|
| 高台・裏山 | 海抜 ≥ 津波高さ × 2 |
| 避難所（地上階） | 避難所の海抜 ≥ 津波高さ × 2 |
| 建物上階 | 海抜 + (階数-1) × 3m ≥ 津波高さ × 2 |
| 移動中（屋外） | 現在位置の標高 ≥ 津波高さ × 2 |

**例**: 津波高さ8mの場合、安全ラインは海抜16m以上

#### 避難所別の安全性（津波8m想定時）

| 避難所 | 海抜 | 安全ライン(16m) | 判定 |
|--------|------|-----------------|------|
| 江名公民館 | 20m | ✅ 安全 | 生存 |
| 健登師記念会館 | 22m | ✅ 安全 | 生存 |
| 江名小学校 | 25m | ✅ 安全 | 生存 |
| 望洋荘 | 28m | ✅ 安全 | 生存 |
| 豊間中学校 | 30m | ✅ 安全 | 生存 |
| 諏訪神社 | 35m | ✅ 安全 | 生存 |
| 中田山（高台） | 40m | ✅ 安全 | 生存 |
| 海岸付近 | 5m | ❌ 危険 | 死亡 |
| 低地住宅地 | 10m | ❌ 危険 | 死亡 |

### 5.7 測定指標

| カテゴリ | 指標 | 検証内容 |
|---------|------|---------|
| **生存率** | 津波到達時生存率 | 海抜 ≥ 津波高さ×2 の位置にいた割合 |
| **避難行動** | 避難開始時刻 | 情報受信から行動開始までの時間 |
| | 指定避難所選択率 | 事前知識の避難所を選んだ割合 |
| | 高台避難率 | 海抜30m以上を選択した割合 |
| | 避難先変更率 | 8分時点の更新後に避難先を変えた割合 |
| **情報への反応** | 警報更新後の行動変化率 | 更新情報を受けて行動を変えた割合 |
| | 高度情報参照率 | LLMが高度を理由に挙げた割合 |
| **負の影響** | パニック行動発生率 | 無計画な経路変更の発生 |
| | 避難遅延率 | 情報待ちによる遅延 |

### 5.8 期待される結果

| 条件 | 避難開始 | 避難先選択 | 生存率 | リスク |
|------|---------|-----------|--------|--------|
| A（標準） | 遅い | 指定避難所中心 | 中程度 | 正常性バイアス |
| B（切迫） | 早い | 指定避難所中心 | 中〜高 | パニック可能性 |
| C（詳細） | 中程度 | 高台分散 | 高い | 情報処理負荷 |
| D（詳細+切迫） | 早い | 高台分散 | 最高 | 情報過多リスク |

### 5.9 分析観点

1. **事前知識の上書き効果**
   - 行政の追加情報で「指定避難所」から「より高い場所」への切り替えが起きるか
   - どの条件で最も効果的に事前知識を修正できるか

2. **情報の具体性 vs 切迫感**
   - 具体的な避難先指示と感情的な切迫感、どちらが効果的か
   - 両方を組み合わせた場合の相乗効果・相殺効果

3. **正常性バイアスの解除**
   - 「予想高さ3m」という初報で避難しない住民の割合
   - 警報更新で行動変容が起きるか

4. **情報更新タイミングの影響**
   - 8分時点の更新で間に合うか
   - より早い更新（5分）と遅い更新（12分）の比較（FutureWork）

## 付録B: トラブルシューティング

### 問題1: LLM応答がタイムアウトする

**原因**: OpenAI API負荷またはネットワーク遅延
**対処**:
- タイムアウト値を延長（30秒→60秒）
- リトライ機能を有効化

### 問題2: エージェントが動かない

**原因**: NavMesh生成の問題
**対処**:
- NavMeshを再生成
- エージェントの初期位置がNavMesh上にあるか確認

### 問題3: ログが出力されない

**原因**: ログディレクトリの権限問題
**対処**:
- ディレクトリの書き込み権限を確認
- ログパスの設定を確認
