# 平成23年東日本大震災における避難行動等に関する面接調査（住民）分析結果

**出典**: 内閣府・消防庁・気象庁共同調査（資料1）  
**調査対象**: 岩手県、宮城県、福島県の沿岸地域避難者 870名  
**調査手法**: 面接方式

## 1. 避難行動パターンの分類とリスク

被災者の避難行動は、地震発生後のタイミングと状況により以下の3つ（+避難不要）に分類される。避難開始が遅れるほど津波遭遇リスクが高まることが実証されている。

* **A: 直後避難（57%）**
  * 揺れがおさまった直後に避難を開始した層。
  * 津波による被害（巻き込まれ・濡れ）の遭遇率は極めて低い。
* **B: 用事後避難（31%）**
  * すぐには避難せず、何らかの行動（片付け、家族への連絡等）を終えてから避難した層。
* **C: 切迫避難（11%）**
  * 避難行動の最中に津波が迫ってきた層。
  * **津波への遭遇率が最も高い（死の危険に直面した層）。**

## 2. 避難の意思決定要因（トリガー）

避難を開始する最大のきっかけは「物理的脅威（揺れ）」であるが、地域社会による「社会的影響」も無視できない要因となっている。

* **物理的要因**: 「大きな揺れから津波が来ると思った」が全体で **48%** と最多。
* **社会的要因**: 「家族または近所の人が避難しようと言ったから」が **20%**。
  * **地域差**: 特に**福島県では「家族・近所の声かけ」が35%** と高く、コミュニティによる相互作用が避難の強い動機付けとなっている。
* **情報的要因**: 「津波警報を見聞きした」は **16%**。

## 3. 避難遅延の理由（阻害要因）

「B: 用事後避難」および「C: 切迫避難」の層が、即座に避難しなかった主な理由は、**正常性バイアス**と**社会的責務（家族）**に大別される。

### (1) 正常性バイアス・リスク認知の欠如

特に「C: 切迫避難」層において顕著に見られた。

* 「過去の地震でも津波が来なかったから」（全体11%、C層で22%）
* 「自分のいる場所には津波は来ないだろうと思った」（位置的な安全神話）
* 「津波のことは考えつかなかった」

### (2) 家族・行動的要因

迅速な避難を物理的に阻害する行動が多くとられていた。

* **「自宅に戻ったから」**: 22%
* **「家族を探しに行く・迎えに行く」**: 21%
* **「家族の安否を確認していた」**: 13%

## 4. 津波警報と意識のギャップ

* **警報の受容**: 大津波警報を見聞きした人は全体の約4割にとどまる。
* **行動変容**: 警報を見聞きした人の約80%は「避難の必要性」を感じており、警報伝達は有効である。
* **課題**: 防災行政無線の内容が「はっきりと聞き取れなかった」人が一定数（岩手・宮城で約20〜25%）存在した。

## 5. 教訓と示唆

調査結果から導き出された主な教訓は以下の通りである。

1. **早期避難の重要性**: 津波襲来を「20分以内」と予想していた人は直後避難する傾向が強い。
2. **正常性バイアスの払拭**: 「ここなら来ない」「過去も大丈夫だった」という思い込みが逃げ遅れの主因。
3. **安否確認の課題**: 家族を探す・戻る行動が避難を遅らせるため、事前に連絡手段や集合場所を決めておく必要がある。
