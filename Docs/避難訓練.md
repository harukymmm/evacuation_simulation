# 津波避難における人間行動の数理的・心理的特性とLLMエージェントへの記憶実装のための包括的研究報告

津波災害時における住民の避難意思決定プロセスは、単なる地理的移動の最適化問題ではなく、個人の認知バイアス、家庭内での社会的役割、地域社会への帰属意識、そして過去の防災教育によって形成された「エピソード記憶」と「手続き的記憶」が複雑に交差する動的なプロセスである。本報告書は、大規模言語モデル（LLM）を用いた避難シミュレーションエージェントの記憶設計を目的とし、実際の教育現場での指導実態、住民の意識変容、および行動統計に基づいた深層的な分析を提供する。特に、エージェントが「訓練経験者」としての妥当な反応を示すために必要なプロンプトの論理的根拠を、実証データと行動心理学の観点から定式化する。

## 第1部：「即時避難と戻り防止」の教育実態と規範の内面化

津波避難において、生存率を決定づける最も致命的な要因は、避難開始後の「戻り行動」の有無である。教育現場では「一度逃げたら戻らない」という鉄則が強調されるが、これをLLMエージェントに実装するためには、単なる禁止命令ではなく、なぜ人間が戻ろうとするのか、そして訓練がどのようにその衝動を抑制するのかというメカニズムを理解しなければならない。

### 1.1 戻り行動の心理的・統計的実態

東日本大震災における生存者の行動解析によれば、地震発生直後に直ちに安全な場所へ避難した者は全体の57%に留まり、驚くべきことに31%の者が「いったん自宅に戻る」という致死的な選択をしていた 。この戻り行動は、生存者のうち「助かったけれども危険な状態であった」とされる11%の人々と合わせ、犠牲者削減のために改善すべき最大のターゲットとされる 。

戻り行動の主たる動機は、家族や知人の安否確認および探索である。地震発生直後（5分以内）には、避難者の39%が「家族や親戚の探索」を目的に行動しており、この割合は発生10〜15分後においても25%と、高い水準で維持される 。これは、人間にとって「家族の安全」が「自己の生存」と同等、あるいはそれ以上の優先順位を持つことを示唆している。

|**地震発生後の行動区分**|**該当割合（生存者870名対象）**|**リスク評価**|
|---|---|---|
|直ちに安全な場所へ避難|57%|低|
|いったん自宅へ戻る（戻り行動）|31%|極めて高|
|危険な状態での生存（避難遅滞）|11%|高|
|最初から安全な場所にいた|1%|なし|

### 1.2 訓練経験がもたらす行動変容

訓練経験者と未経験者の間には、この「戻り行動」の抑制において決定的な差が生じる。行政相談委員へのアンケートによれば、訓練未経験者は「夜間の避難」や「高齢者の同伴」に対して強い不安を抱き、行動の遅滞を招く傾向があるのに対し、訓練経験者は実際の経路や所要時間を「身体知」として保持しているため、不確実性による躊躇が少ない 。

特に、訓練経験者は「津波で死ぬかもしれない」という危機感を「自分事」として捉える能力（自己責任の原則）が強化されている。これは、正常性バイアス（「自分だけは大丈夫」「今回の津波も大したことはない」という思い込み）を打破するための重要な認知的基盤となる 。過去の三陸沿岸では、警報が空振りに終わった経験が「今回も大丈夫だろう」という誤認を生み、3mの津波警報を「実際にはもっと低い」と38.6%の住民が過小評価していた事実がある 。訓練はこの「空振りを恐れない意識」を醸成し、エージェントが「迷わず逃げる」という行動を選択するための記憶の裏付けとなる。

### 1.3 教育現場における「戻り防止」の指導論理

学校教育における防災指導では、単に「戻るな」と命じるのではなく、「戻ることの無意味さと、待つことの意義」をセットで教える傾向がある。例えば、「子どもには一人でも避難することができる知恵を持たせるので、いざという時には子どものことを信用して、保護者も自身の避難を完遂してほしい」というメッセージが発信されている 。これは、避難を「個人の行動」から「家族間の信頼に基づく共同プロジェクト」へと昇華させる試みである。

LLMエージェントへの記憶実装においては、以下の要素を「訓練記憶」の核として定義すべきである：

- **不確実性の受容**: 「家族の安否が不明である」という状態を許容し、それを「事前の信頼関係（後述のてんでんこ）」によって解消する能力。
    
- **情報の優先順位**: 視覚的な被害状況や家族の不在よりも、津波警報という「抽象的な情報」を上位の行動原理として扱う訓練。
    

## 第2部：「津波てんでんこ」と率先避難の社会的力学

「津波てんでんこ」の理念は、しばしば「家族を捨てて自分だけ逃げる冷淡な教え」と誤解されるが、実態は「個々人が自立して避難することで、結果としてコミュニティ全体の生存率を最大化する」という高度な生存戦略である。エージェントが正常性バイアスを打破し、周囲を巻き込む行動をとる根拠は、この理念の内面化に求められる。

### 2.1 「津波てんでんこ」の四つの機能的側面

京都大学の矢守克也教授らの研究によれば、「津波てんでんこ」には単なる避難指示を超えた、以下の四つの多層的な意味が含まれている 。

|**機能的側面**|**具体的意味とエージェントへの応用**|
|---|---|
|**即時避難の促進**|津波が見えてからではなく、地震の揺れを感じた瞬間に各自で行動を開始する。|
|**相互信頼の事前醸成**|「災害時には互いに勝手に逃げる」という約束を事前に交わし、安否確認のための戻り行動を構造的に排除する 。|
|**避難行動の誘発**|自分が逃げる「姿」を他者に見せることで、周囲の同調性バイアスを逆手に取り、避難を促進する。|
|**生存者の自責感低減**|犠牲者が出た際にも「相手もてんでんこしようと最善を尽くしたはずだ」と信じることで、事後の心理的ケアに寄与する 。|

### 2.2 率先避難者（リード・エバキュエーター）の波及効果

「釜石の奇跡」に代表される事例では、日頃の訓練を受けた子どもたちが「率先避難者」として機能し、周囲の大人の避難を誘発したことが知られている 。人間は「周囲が逃げていない」という状況では避難を躊躇するが、「誰かが全力で逃げている」という視覚的情報は、警報音よりも強力な行動トリガーとなり得る。

和歌山県印南町での避難訓練や室内実験の結果によれば、避難を決意した理由として「避難している人を見て」と回答した者は41%に達し、直接的な「誰かに避難しようと言われた（声掛け）」の3%を大きく上回る 。これは、非言語的な行動（背中を見せて走る）が、言語的な説得よりも高い信頼性と緊急性を周囲に伝えることを示している。ただし、この効果は「実際のハザードの現実味」が共有されている場合に最大化されるため、LLMエージェントの記憶には「過去の津波被害の映像知識」や「揺れの強さに対する身体的恐怖」をリンクさせることが不可欠である 。

### 2.3 教育現場での「冷たさ」の克服

「てんでんこ」を教える際、教育現場では「自分勝手に逃げることの肯定」ではなく、「自分の命を守ることが、家族を悲しませない唯一の方法である」という利他的な文脈で語られる 。これにより、エージェントは「家族を見捨てる」という背徳感（自責の念）から解放され、論理的かつ迅速な避難を選択できるようになる。LLMエージェントにおける「家族を探索しない」という制約は、この「信頼の事前構築」というエピソード記憶を背景に持つことで、より人間味のある、かつ合理的な行動として出力される。

## 第3部：移動手段選択における「車両避難」の認知的制約

車両避難は、現代の地域防災計画において「原則禁止」とされているが、現実には世帯構成や地理的条件により、車両を選択せざるを得ない葛藤が存在する。LLMエージェントが「徒歩」を強く優先する判断を下すためには、車両避難に伴う「渋滞による死のリアリティ」が記憶として刻まれていなければならない。

### 3.1 自治体マニュアルと車両利用の実態

沿岸自治体のハザードマップや訓練マニュアルでは、車両避難による渋滞が避難の致命的な遅れを招くため、「原則徒歩」が徹底して指導されている 。高知県などの大規模避難マニュアルにおいても、避難指示は迅速な移動を前提としており、車両の滞留は救急活動や他者の避難を妨げる「公害」として扱われることもある 。

しかし、アンケート調査によれば、8.2%の住民が依然として自動車を選択しており、その主な理由は「避難先が遠い（徒歩圏内にない）」ことや「身体の不自由な高齢者の同伴」である 。

|**世帯人数・属性**|**車両避難を選択する割合**|**統計的傾向**|
|---|---|---|
|単身世帯|18%|低|
|5人以上の多人数世帯|35%|高|
|要援護者がいる世帯|30%|高|

### 3.2 訓練経験者と未経験者のリスク認知の差

訓練経験者は、図上訓練（DIG）や実地訓練を通じて、地域の狭隘道路や信号停止による「動かない渋滞」の恐怖を知識として、あるいは模擬体験として保持している。これに対し、未経験者は「車の方が物理的に速い」という素朴な物理法則に基づき判断を行うため、結果として渋滞に巻き込まれるリスクが高い 。

LLMエージェントにおける移動手段の決定論理には、以下の「訓練記憶」による重み付けが必要である：

- **渋滞の不確実性**: 普段は5分で着く場所が、災害時には「物理的な閉塞」により到達不能になるという予測能力。
    
- **夜間の脆弱性**: 夜間停電時には信号が機能せず、車両避難がさらに困難になるというリスク認識（63.9%の行政相談員が夜間対策の不備を指摘している） 。
    
- **徒歩の確実性**: 瓦礫や道路の亀裂があっても、歩行ならば迂回や乗り越えが可能であるという「確実な到達時間」への信頼。
    

エージェントが世帯に高齢者を抱えている場合、訓練未経験エージェントは「迷わず車を選ぶ」が、訓練経験エージェントは「近隣の垂直避難先（津波避難ビル）への徒歩移動」を第一選択肢として検討し、車両は「最終手段」として極めて慎重に扱うという、高度な条件分岐が再現されるべきである。

## 第4部：「空間認知」と避難先（高さ）の選択能力

エージェントが避難先を選択する際、単なる距離の近さ（水平距離）ではなく、標高（高さ）と到達可能性を考慮した判断ができるかどうかが、訓練の効果を測る指標となる。

### 4.1 標高の解像度と訓練の効果

防災訓練や図上訓練（DIG）を経験した住民は、自らの生活圏における「海抜」の情報を、単なる数字ではなく、具体的な風景（「あの公園の入口より先は安全」「あの信号はまだ浸水域内」）として保持している。この「空間・標高の解像度」は、緊急時の意思決定を大幅に加速させる 。

調査によれば、ハザードマップを確認している人は4割程度いるが、「避難場所やルートを家族で共有している」人は2割以下に留まる 。この乖離は、地図上の知識が「エピソード記憶（実際の避難を伴う記憶）」に昇華されていないことを示している。訓練経験を持つエージェントは、この2割の「共有・確認済み層」に属し、自宅以外（職場や買い物先）にいても、直ちに「海抜何メートルの場所がどこか」を想起できる能力を持つと定義される。

### 4.2 垂直避難と水平避難の高度な選択

避難行動には「遠くの高台を目指す水平避難」と「近くの高い建物に逃げる垂直避難」がある。訓練経験者は、以下の状況判断基準を内面化している。

|**避難方法**|**選択すべき状況**|**メリット・デメリット**|
|---|---|---|
|**水平避難**|津波到達まで十分な時間がある、建物耐久性に不安がある場合。|安全性は高いが、移動時間がかかり、途中で津波に捕捉されるリスクがある 。|
|**垂直避難**|浸水が始まっている、夜間で見通しが悪い、移動時間が足りない場合。|迅速に安全を確保できるが、孤立する可能性や長期間の浸水に耐える必要がある 。|

東日本大震災の事例では、自宅の3階へ垂直避難した小学生が、歩行困難な浸水状況を冷静に判断して生き延びた例がある 。LLMエージェントが、shelter_candidatesから「より遠いが高台」と「より近いが建物（垂直）」のどちらを選ぶかは、この「残余時間」と「周囲の状況（浸水開始、夜間、家族の歩行能力）」の精緻なバランスの上に成り立つべきである。

## 第5部：LLMエージェントへの記憶実装のための設計指針

以上の調査結果を統合し、LLMエージェントが「訓練経験者」として振る舞うための具体的なプロンプト設計およびシステム構成の指針を提案する。

### 5.1 階層的メモリ構造の実装

エージェントの記憶を、以下の三つのレイヤーで構築することを推奨する。

1. **プロトコル・メモリ（手続き的記憶）**:
    
    - 「地震＝即避難」という反射的なルール。
        
    - 「車両は原則禁止」という移動手段の制約。
        
    - 「垂直避難 vs 水平避難」の選択アルゴリズム。
        
2. **エピソード・メモリ（個人的体験記憶）**:
    
    - 「過去の訓練で歩いた避難経路の景色、標高、疲労感」。
        
    - 「家族と交わした『てんでんこ』の約束シーン」。
        
    - 「避難訓練で見かけた近隣住民の顔ぶれ（共助の期待値）」 。
        
3. **コンテキスト・メモリ（状況認識記憶）**:
    
    - 「現在は夜間であるため、移動速度を20%下方修正する」。
        
    - 「周囲が逃げ始めたので、同調性バイアスを正の方向に利用する」。
        

### 5.2 心理的バイアスの「抑制」と「利用」

エージェントは、人間が持つ認知バイアスを理解しつつ、訓練によってそれを制御するプロセスを示す必要がある。

- **正常性バイアスの打破**: 「大したことはないだろう」という内なる声を、訓練記憶（「過去の空振り経験は、安全の証明ではない」という教訓）が上書きするプロセスをログに出力させる。
    
- **率先避難の遂行**: 「自分が最初に走り出すことで、隣の家の老夫婦も避難を開始するかもしれない」というメタ認知（社会的影響力の認識）を避難の動機に含める。
    

### 5.3 家族探索衝動のモデリング

「家族を探しに戻らない」という行動は、エージェントにとって最も大きな葛藤（Conflict）となる。これを「家族への愛情がない」と表現するのではなく、「家族との強固な信頼（てんでんこ）があるからこそ、再会場所を目指して突き進む」という論理で構築する。この際、「家族も訓練を受けているはずだ」という信頼の重みをパラメータ化することで、エージェントの行動に説得力が生まれる。

## 結論

本調査報告が示す通り、防災訓練は単なる知識の付与ではなく、極限状況における「意思決定の自動化」と「心理的葛藤の解消」を目的としている。LLMエージェントに避難訓練の記憶を実装する意義は、理想的なロボット的行動を再現することではなく、人間らしい弱さ（戻りたい衝動、車を使いたい誘惑）を訓練によって克服した「教育された主体」としての行動を再現することにある。

本報告書で詳述した統計データ、特に戻り行動の31%という実態や、車両利用と世帯構成の相関、率先避難の誘発効果などは、エージェントの意思決定確率を規定する数値的根拠として機能する。また、「津波てんでんこ」に代表される哲学的背景は、エージェントが生成する対話や思考プロセスの質的深みを担保するものである。これらの知見を基盤としたエージェント実装は、被災地の防災意識が薄れつつある現代（約8割が薄れを感じている現状 ）において、テクノロジーを用いた新たな防災教育・シミュレーションの地平を切り拓くものと確信される。
