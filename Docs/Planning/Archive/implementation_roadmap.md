## 2. 未実装・要強化項目

### 2.1 優先度：高（実験実施に必須）

#### 2.1.1 RAG（検索拡張生成）による地域知識の統合

**論文での記載**
> 長期記憶の保存と検索には、テキスト埋め込み（Text Embedding）を用いる。OpenAIのtext-embedding-3-smallモデルにより、テキストを1536次元のベクトルに変換し、ベクトルデータベースに保存する。

**現状**
- 実装されていない
- 現在はペルソナ情報をシステムプロンプトとして毎回提供するのみ

**必要な実装**
- [ ] テキスト埋め込みモデルの導入
- [ ] ベクトルデータベースの構築（例：Pinecone, Weaviate, FAISS）
- [ ] 地域知識（避難所情報、危険区域、過去の災害経験など）の登録
- [ ] 質問に対する関連記憶の検索機能
- [ ] 信頼度閾値（0.75以上）による記憶抽出

---

#### 2.1.2 記憶の圧縮と要約

**論文での記載**
> 短期記憶は毎回の意思決定時にプロンプトとしてLLMに投入されるが、時間経過とともに大量の情報が蓄積され、LLMのコンテキスト長制限を超えるリスクがある。そこで、記憶の圧縮と要約を実装する。

**現状**
- 会話履歴の保持はあるが、圧縮・要約機能は未実装

**必要な実装**
- [ ] 過去の行動履歴の要約機能
- [ ] コンテキスト長の管理
- [ ] 重要情報の抽出・保持ロジック

---

#### 2.1.3 エージェント間のコミュニケーション機能の完全実装

**論文での記載**
> 通信範囲は半径30メートルとし、範囲内のエージェントに対してメッセージを送信できる。

**現状**
- TALK行動の基本構造は実装済み
- 会話リクエスト・レスポンスの構造は定義済み

**必要な実装**
- [ ] 情報伝達メカニズムの完全実装（津波情報、避難所情報、道路通行可否）
- [ ] 受信した情報による意思決定への影響反映
- [ ] 情報の伝播シミュレーション

---

#### 2.1.4 500体規模のエージェント生成

**論文での記載**
> エージェント数は500体と設定する。実際の住民構成比を反映したペルソナを生成。

**現状**
- ペルソナ設定機能は実装済み
- 大規模なCSVファイルは存在（fukushima_evacuation_personas_500.csv）

**必要な実装**
- [ ] いわき市平地区の人口統計データに基づくペルソナ分布の検証
- [ ] 年齢層分布：10歳未満10%、10代10%、20-30代20%、40-50代25%、60代以上35%
- [ ] 家族構成：単身20%、夫婦のみ25%、夫婦と子供30%、三世代25%
- [ ] 身体能力：健常者85%、移動困難者13%、要介護者2%
- [ ] 職業・役割：一般90%、医療職3%、公務員5%、消防団員2%
- [ ] 移動速度の年齢・身体能力による設定

---

#### 2.1.5 エージェント初期配置システム

**論文での記載**
> エージェントの初期配置は、発災時刻と人口統計に基づいて決定する。

**現状**
- 建物カテゴリに基づくスポーン管理は実装済み

**必要な実装**
- [ ] 在宅率（平日昼間20-30%）の設定
- [ ] 外出率（70-80%：職場、学校、商業施設）の設定
- [ ] 家族メンバーの分散配置ロジック
- [ ] 発災時刻による配置パターンの切り替え（平日14時 vs 休日夜間20時）

### 2.2 優先度：中（実験の質向上に重要）

#### 2.2.1 視界・環境認識システムの拡充

**論文での記載**
> 視界範囲は半径100メートルとし、視界は方向ごとに分割し（北、北東、東、南東、南、南西、西、北西の8方向）、各方向に見えるオブジェクトを自然言語で記述してLLMに提供する。

**現状**
- 周辺建物情報の取得は実装済み
- 8方向への分割記述は未実装

**必要な実装**
- [ ] 8方向への視界分割
- [ ] 方向ごとの環境情報記述生成
- [ ] 動的な環境変化の検知（他エージェントの移動方向など）

---

#### 2.2.2 建物倒壊危険度の評価

**論文での記載**
> 建物の倒壊危険度は、PLATEAUの構造タイプ（木造は危険度高、鉄筋コンクリート造は危険度低）と建築年（古い建物ほど危険度高）から推定する。

**現状**
- 建物分類機能は実装済み
- 倒壊危険度の計算は未実装

**必要な実装**
- [ ] 構造タイプによる危険度評価
- [ ] 建築年データの取得・活用（PLATEAUデータから）
- [ ] 危険度情報のLLMへの提供

---

#### 2.2.3 斜面危険度の評価

**論文での記載**
> 斜面の危険度は、地形の勾配から計算し、急斜面は避難経路として選択されにくくする。

**現状**
- 未実装

**必要な実装**
- [ ] 地形勾配の計算
- [ ] 斜面危険度の経路選択への反映

---

#### 2.2.4 定性的評価指標の収集

**現状**

**必要な実装**
