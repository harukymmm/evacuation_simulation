# Connection（社会的相互作用）仕様書

## 概要

本モジュールは、避難シミュレーションにおけるエージェント間の社会的相互作用を定義する。3つの主要なアクション（TALK、CONTACT、FOLLOW）により、エージェントは他者との情報交換・連絡・追従行動を実現する。

---

## 1. TALK（会話）

### 1.1 機能概要

エージェントが周辺の他のエージェントに話しかけ、情報交換や相談を行うアクション。避難所情報の共有、現状確認、行動相談などを目的とする。

### 1.2 処理フロー

```
話しかける側（発話者）
    ↓ 会話リクエストを送信
話しかけられた側（応答者）
    ↓ LLMで応答を生成
    ↓ 応答を返信
発話者が応答を受信し、会話履歴に記録
```

### 1.3 会話トピック

| トピック | 説明 |
|----------|------|
| ShelterInfo | 避難所の場所や状況に関する情報交換 |
| CurrentSituation | 現在の状況確認 |
| ActionAdvice | 行動に関する相談・助言 |
| SafetyConfirm | 安全性の確認 |
| General | 一般的な会話 |

### 1.4 パラメータ

| パラメータ | 値 | 説明 |
|-----------|-----|------|
| 連続回数制限 | 2回 | 連続して会話できる最大回数 |
| 会話履歴保持数 | 5件 | 記憶される直近の会話履歴 |
| 応答タイムアウト | 5秒 | 応答を待機する最大時間 |
| 周辺検索人数 | 最大5人 | LLMに送信される周辺避難者情報の上限 |

### 1.5 LLM連携

- **発話者**: LLMが会話対象・トピック・メッセージ内容を決定
- **応答者**: LLMが応答内容と情報共有の意思を生成
- **フォールバック**: LLM失敗時はトピックに基づくデフォルト応答を使用

### 1.6 記録される情報

会話履歴として以下の情報が保存される：
- 会話時刻
- 会話相手の識別子・名前
- 話題
- 自分のメッセージ
- 相手の返答
- 自分から話しかけたかどうか

## 2. CONTACT（家族連絡）

### 2.1 機能概要

エージェントが家族メンバーに連絡を取り、安否確認や情報交換を行うアクション。連絡対象がシミュレーション内に存在するか否かで処理が分岐する。

### 2.2 処理フロー

#### シミュレーション内の家族

```
連絡送信者
    ↓ 連絡リクエストを送信
家族エージェント
    ↓ LLMで応答を生成
    ↓ 応答を返信
送信者が応答を受信
```

#### シミュレーション外の家族

```
連絡送信者
    ↓ サーバーにリクエスト送信
サーバー
    ↓ 家族のペルソナを用いてLLMで応答を生成
    ↓ 応答を返信
送信者が応答を受信
```

### 2.3 連絡内容

#### 送信情報
- 送信者の識別子・名前・続柄
- メッセージ内容
- 現在の行動・目標避難所
- 現在位置の説明

#### 応答情報
- 応答者の識別子・名前
- 返信メッセージ
- 現在の状態（無事、軽傷、重傷など）
- 現在位置の説明
- 今後の行動予定

### 2.4 パラメータ

| パラメータ | 値 | 説明 |
|-----------|-----|------|
| 連続回数制限 | 2回 | 連続して連絡できる最大回数 |
| 応答タイムアウト | 10秒 | 応答を待機する最大時間 |

### 2.5 続柄の相互変換

連絡を受けた側が自分の続柄を推定する際の変換規則：
- 妻 ↔ 夫
- 息子/娘 → 親
- 父/母 → 子ども
- 兄/弟/姉/妹 → 兄弟姉妹

### 2.6 LLM連携

- **送信者**: LLMが連絡対象・メッセージ内容を決定
- **応答者**: LLMが応答内容・現在状態・今後の行動を生成
- **シミュレーション外の家族**: サーバー側でペルソナに基づき応答を生成

## 3. FOLLOW（追従）

### 3.1 機能概要

エージェントが周辺の他のエージェントについて行くアクション。追従者と追従対象の双方向の依存関係を管理し、行動の同期を実現する。

### 3.2 処理フロー

```
追従者
    ↓ 追従対象を選択
    ↓ 追従対象に自身を登録
追従対象
    ↓ 行動変更時に全追従者に通知
追従者
    ↓ 通知を受けて行動を同期
```

### 3.3 追従動作

追従対象の行動に応じた追従者の動作：

| 追従対象の行動 | 追従者の動作 |
|---------------|-------------|
| 避難所へ移動 | 同じ避難所を目指す |
| その場で待機 | 同じように待機 |
| その他 | 追従対象の位置を追従 |
| 避難完了 | 同じ避難所に向かい、追従を終了 |
| 消失 | 自動的に避難行動に切り替え |

### 3.4 パラメータ

| パラメータ | 値 | 説明 |
|-----------|-----|------|
| 周辺検索半径 | 30m | 追従対象を探す範囲 |
| 追従距離 | 2m | 追従対象に近づく際の停止距離 |
| 追従チェック間隔 | 1秒 | 追従位置を更新する間隔 |

### 3.5 追従者管理

追従対象は以下の機能で追従者を管理する：
- **登録**: 追従者が追従を開始する際に登録
- **削除**: 追従者が追従を終了する際に削除
- **行動変更通知**: 追従対象の行動が変わった際に全追従者に通知
- **消失通知**: 追従対象が消えた際に全追従者に通知

### 3.6 LLM連携

- **追従開始**: LLMが追従対象を決定
- **行動変更検知**: LLMが新しい行動を判断（LLM無効時は自動同期）

## 4. 周辺避難者検出

### 4.1 検出方法

指定された検索半径内の全避難者を検出し、距離順にソートして返却する。

### 4.2 取得情報

各避難者について以下の情報を取得：
- 識別子
- 現在位置
- 距離（メートル）
- 現在の行動
- 目標避難所
- 名前・役割・年齢層

### 4.3 混雑度計算

検出された人数から混雑度を計算：
```
混雑度 = (検出人数 / 検索範囲面積) × 100
```
単位は「100平方メートルあたりの人数」

## 5. 無限ループ防止機構

社会的行動の無限ループを防止するための制限：

| アクション | 制限 | 制限超過時の動作 |
|-----------|------|-----------------|
| TALK | 連続2回まで | 避難行動に切り替え |
| CONTACT | 連続2回まで | 避難行動に切り替え |
| FOLLOW | 追従対象の消失時 | 避難行動に切り替え |

## 6. エラーハンドリング

### 6.1 TALK

| エラー状況 | 対処 |
|-----------|------|
| LLM失敗 | トピックに基づくデフォルト応答を使用 |
| 対象が見つからない | 避難行動に切り替え |
| 応答タイムアウト | デフォルト応答を使用 |

### 6.2 CONTACT

| エラー状況 | 対処 |
|-----------|------|
| LLM失敗 | デフォルト応答を使用 |
| 対象が見つからない | 避難行動に切り替え |
| 連続回数超過 | 避難行動に強制切り替え |

### 6.3 FOLLOW

| エラー状況 | 対処 |
|-----------|------|
| 追従対象の消失 | 避難行動に切り替え |
| 追従対象の避難完了 | 同じ避難所に向かい、追従を終了 |

- 応答者識別子

- 識別子
