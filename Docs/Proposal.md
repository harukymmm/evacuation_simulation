# 背景

## 避難シミュレーションにおける従来手法の限界

- トップダウンモデル（流体モデル等）</br>群衆全体を「流れ」や「平均値」として扱うマクロなアプローチ
  - 個人の多様性（年齢、身体能力、リスク認識）を軽視
  - 局所的な相互作用（パニック、協調）を再現不可
- 想定外の渋滞や避難所の混乱に繋がりかねない

---

# 背景

## エージェント・ベース・モデリング（ABM）の台頭

個（エージェント）のルールから全体の現象をみるボトムアップ型

- 強み：
  - 個人の異質性を設定可能
  - 混雑などの創発現象の再現に成功（e.g.,社会力モデル）
- 現行の課題：
 	- エージェントの知能が単純なルールベースに依存
  		- 現実の人間の複雑な社会的・心理的側面の再現が困難

---

# 背景

## LLMエージェントの導入

- LLMをエージェントの「頭脳」として用いることで、人間らしい記憶の形成、推論、そして自然言語による相互作用が可能な</br>シミュレーションが実現しつつある
- 人間らしい多様な意思決定
  - ペルソナの提供により多様かつリアルな行動が期待できる
- 文脈への適応
  - 多様なシナリオに対しても柔軟に対応
  - プロンプトやRAGによるカスタマイズ性も高い

---

# 目的

- 現実の人間と指示遵守のエージェントの間のギャップを埋める
- 検証内容
  - LLMエージェントの導入により、正常性バイアス・同調などを反映した現実的な避難行動が再現できるかどうか
  - ペルソナにより個々人の持つ多様性を再現できるかどうか
  - RAGによる地域情報の提供が有意かどうか
- 現実に近い人間行動を再現し、ボトルネック特定と実効的対策へ
  - 指標化: 避難時間の分散、避難完了時間、避難所キャパ比

---

# 期待インパクト

- 人間行動起因のボトルネック可視化と介入案の検証</br>⇨F-REIとの提携による今後の改善に
- 地域知識（RAG）に基づく地域の特徴に適応した設計
- 貢献：個別最適と全体最適の両立
  - **科学的貢献**: </br>物理×認知×知識を統合したLLM×ABMの設計
  - **社会的価値**:</br> 高リスク層の到達率向上、最悪事例の短縮、訓練高度化
  - **展開可能性**: 他地域/他災害への移植、運用組織の手順改善

# 関連研究

![right example](assets/FireEvacuation.png)

## CA火災避難×LLM

- セル単位のLLM避難シミュレーション
- 煙・可視性データを入力し、視界記述→推論→セル移動を反復
- LLM規模が大きいほど避難効率向上、適応的な探索行動が出現

**背景設定の影響**

- 「友人と会う予定」→自発的に友人探索（危険領域も通過）

**コミュニケーションの影響**

- 火災情報の伝達で避難時間が**半分に短縮**（158秒→82秒）

# 検証

- 対照実験
  - ① ルールベースABM（ベースライン: 最短・固定遵守）
  - ② 心理・社会パラメータ付きABM（正常性バイアス/同調）
  - ③ LLM＋RAGエージェントABM（認知・通信・地域知識）
  - 初期配置/需要/ハザードは固定、N試行の平均と分散で比較
- 実際の避難データがあればペルソナ、RAGの有無によって現実の結果に近づいたかどうかを検証

---

# 評価指標

- **時間**: 平均/中央値、避難完了率
- **流れ**: 渋滞発生時間・キュー長・混雑持続
- **行動**: 行動分散度/指示遵守率/再計画回数、避難所到達率
