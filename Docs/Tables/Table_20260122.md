## 実験2: 認知バイアスが避難行動に与える影響

認知バイアスの付与が避難行動に与える影響を検証するため、4つの条件を設定した。
- 条件1（ベースライン）: 認知バイアスなし（ペルソナの既存mental_stateを使用）
- 条件2（正常性バイアス）: 全エージェントに正常性バイアスを付与

- 条件4（複合）: 正常性バイアスと同調バイアスの両方を付与

### 表19: 実験2の主要知見

| 項目 | 観察結果 | 解釈 |
|:-----|:---------|:-----|
| 避難完了率のばらつき | 46.5%〜81.5%（標準偏差15.1%） | 認知バイアスの種類により避難完了率に大きな差異 |
| 正常性バイアスの影響 | 条件2で避難完了率46.5%（-33pt変化） | 正常性バイアスは避難行動を大幅に遅延させる |
| 同調バイアスの影響 | 条件3で避難完了率81.5%（+2pt変化） | 同調バイアスは集団的避難行動を促進する |
| 複合バイアスの影響 | 条件4で避難完了率55.4% | 正常性バイアスと同調バイアスが競合 |
| STAY行動の増加 | 条件2でSTAY選択率36.48%（+17pt変化） | 正常性バイアスが待機行動を促進 |
