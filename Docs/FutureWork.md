## 1. 土砂災害リスク区域の通行制御

### 概要
土砂災害特別警戒区域等の危険性が高い部分を、NavMeshと連携して通行不可または回避対象にする機能。

### 目的
- 地震後の二次災害リスクが高い区域を避難経路から除外
- より現実的な避難行動のシミュレーション

### 実装方法の候補

- [ ] **方法A: NavMeshObstacle動的生成**
  - 実行時に土砂災害特別警戒区域のBoundsに基づいてNavMeshObstacleを生成
  - メリット: 災害フェーズに応じて動的に制御可能
  - デメリット: 大量のObstacle生成によるパフォーマンス低下の懸念

- [ ] **方法B: NavMesh Area設定（事前Bake）**
  - 土砂災害区域を別のNavMesh Areaとして設定し、コストを高く設定
  - メリット: 実行時の負荷が低い
  - デメリット: シーンごとにNavMeshのRe-Bakeが必要

- [ ] **方法C: エージェント側での回避判断**
  - NavMeshを変更せず、Evacuee側で経路上の土砂災害区域を検出し回避
  - メリット: NavMesh変更不要、実装が比較的容易
  - デメリット: 最短経路計算には反映されない

### 関連ファイル
- `Assets/Scripts/EnvironmentalContextProvider.cs` - 土砂災害区域の判定
- `Assets/Scripts/GeoSpatialIndex.cs` - 土砂災害データの保持
- `Assets/Scripts/Evacuee.cs` - 避難者の経路制御

## 2. DEM（地形）データの高度な活用

### 概要
現在は概算標高のみ取得しているDEMデータを、傾斜情報や高台方向の判定に活用する。

### 実装項目

- [ ] **傾斜角度の計算**
  - DEMメッシュの頂点データから傾斜角度を算出
  - GeoSpatialIndexBaker.csでBake時に計算
  - TerrainEntryに`averageSlope`, `maxSlope`フィールドを追加

- [ ] **高台方向の判定**
  - 現在位置から見て標高が高い方向を算出
  - 津波避難時の「高台へ向かう」判断に利用

- [ ] **坂道の認識と経路選択への反映**
  - 「この先は急な坂道がある」等の環境認識表現
  - 高齢者・身体障害者の経路選択への影響

- [ ] **正確な標高取得（レイキャスト）**
  - 現在のBounds平均ではなく、DEMメッシュへのレイキャストで正確な標高を取得

### 関連ファイル
- `Assets/Scripts/GeoSpatialIndex.cs` - TerrainEntryの拡張
- `Assets/Editor/GeoSpatialIndexBaker.cs` - 傾斜計算の追加
- `Assets/Scripts/EnvironmentalContextProvider.cs` - 傾斜取得メソッドの追加

## 6. ペルソナによる環境認識の差異

### 概要
避難者のペルソナ（土地勘レベル、年齢、過去の災害経験等）に応じて環境認識の詳細度を変える。

### 実装項目

- [ ] **土地勘レベルによる差異**
  - native: 詳細な土地知識（「この先の崖は昔崩れたことがある」）
  - resident: 一般的な土地知識
  - newcomer: 見た目の情報のみ

- [ ] **過去の災害経験による差異**
  - 経験者: 危険箇所をより強く認識
  - 未経験者: 危険の認識が薄い

### 関連ファイル
- `llm_server/server.py` - ペルソナに応じたプロンプト分岐
