# 防災行政無線スピーカーの設定方法

## 概要

`EmergencyBroadcastSpeaker` コンポーネントを Unity シーン内の GameObject にアタッチすることで、防災行政無線（屋外スピーカー）を配置できます。

避難者がスピーカーから一定距離以内にいる場合、その放送を「聞いた」ことになり、LLM の判断に影響します。

---

## 設定手順

### **ステップ1: スピーカー用のGameObjectを作成**

1. Unity Editor でシーンを開く
2. Hierarchy で右クリック → `Create Empty` を選択
3. 作成された GameObject の名前を変更（例: `Speaker_CityHall`、`Speaker_School` など）

### **ステップ2: 位置を設定**

1. 作成した GameObject を選択
2. Inspector の `Transform` で、スピーカーを配置したい座標を設定
   - 例: 市役所の屋上 → `(5000, 20, 0)`
   - 例: 小学校の校舎 → `(3800, 5, -1500)`

**位置の決め方：**

- PLATEAU の建物データがある場合、その建物の `Transform.position` や `Renderer.bounds.center` を参考にする
- 実際の地図データがあれば、それに基づいて座標を設定
- シーン内で `Gizmos` を有効にすると、可聴範囲が視覚的に確認できる（黄色のワイヤースフィア）

### **ステップ3: EmergencyBroadcastSpeaker コンポーネントをアタッチ**

1. 作成した GameObject を選択した状態で
2. Inspector の下部にある `Add Component` ボタンをクリック
3. `Emergency Broadcast Speaker` を検索して追加

### **ステップ4: パラメータを設定**

Inspector で以下のパラメータを設定します：

#### **可聴範囲設定**

- **`Audible Radius Meters`** (デフォルト: 500)
  - このスピーカーから聞こえる最大距離（メートル）
  - 例: 市役所の大型スピーカー → `800`
  - 例: 小学校の小型スピーカー → `400`

#### **放送内容**

- **`Broadcast Message`** (テキストエリア)
  - このスピーカーから流す放送内容（日本語）
  - 例: `"津波警報が発表されました。海岸から離れて高台に避難してください。"`
  - 例: `"地震が発生しました。建物の外に出て安全な場所に避難してください。"`

#### **放送タイミング**

- **`Broadcast Start Time Seconds`** (デフォルト: 10)
  - シミュレーション開始から何秒後に放送を開始するか
  - 例: `10` = 開始10秒後
  - 例: `0` = 開始直後

- **`Broadcast Duration Seconds`** (デフォルト: 30)
  - 放送が継続する時間（秒）
  - 例: `30` = 30秒間放送
  - 例: `0` = 1回だけ放送（瞬間的）

#### **デバッグ表示**

- **`Show Gizmos`** (デフォルト: true)
  - Scene ビューで可聴範囲を黄色のワイヤースフィアとして表示するかどうか
  - 設定時に可視化できるので便利

## 設定例

### **例1: 市役所の大型スピーカー**

```
GameObject名: Speaker_CityHall
位置: (5000, 20, 0)
Audible Radius Meters: 800
Broadcast Message: "津波警報が発表されました。海岸から離れて高台に避難してください。"
Broadcast Start Time Seconds: 15
Broadcast Duration Seconds: 60
```

### **例2: 小学校のスピーカー**

```
GameObject名: Speaker_School
位置: (3800, 5, -1500)
Audible Radius Meters: 400
Broadcast Message: "地震が発生しました。校庭に避難してください。"
Broadcast Start Time Seconds: 5
Broadcast Duration Seconds: 30
```

### **例3: 複数のスピーカーを配置**

同じシーン内に複数の `EmergencyBroadcastSpeaker` を配置できます。

- 避難者が複数のスピーカーの可聴範囲内にいる場合、**最初に聞いた放送内容**が記録されます
- 異なる放送内容が流れる場合、**最新の放送内容**で上書きされます

## 自動検出 vs 手動設定

### **自動検出（推奨）**

`AlertManager` コンポーネントの `Auto Find Speakers` が `true` の場合（デフォルト）、
シーン内の全 `EmergencyBroadcastSpeaker` が自動的に検出されます。

**メリット：**

- スピーカーを追加するだけで自動的に動作
- 手動でリストに追加する必要がない

### **手動設定**

`AlertManager` の `Auto Find Speakers` を `false` にし、
`Speakers` リストに手動でスピーカーを追加することもできます。

**用途：**

- 特定のスピーカーのみを有効にしたい場合
- テスト用に一部のスピーカーを無効化したい場合

## 可聴範囲の判定ロジック

### **距離判定（シンプルな実装）**

現在の実装では、**単純な3D距離**で判定しています：

```
避難者の位置: (x1, y1, z1)
スピーカーの位置: (x2, y2, z2)
距離 = √((x1-x2)² + (y1-y2)² + (z1-z2)²)

if (距離 <= audibleRadiusMeters) {
    // 聞こえた
}
```

### **判定タイミング**

- `AlertManager` が `Update()` で **1秒ごとに** チェック
- 放送中（`IsBroadcasting()` が `true`）の間、継続的に判定
- 避難者が可聴範囲内に入った瞬間に `OnHeardBroadcast()` が呼ばれる

### **遮蔽（建物による音の遮断）について**

現在の実装では、**建物による遮蔽は考慮していません**。

- 建物の陰にいても、距離さえ近ければ「聞こえた」と判定される
- よりリアルな実装が必要な場合は、`Raycast` で建物コライダーをチェックする拡張が可能

## 動作確認方法

### **1. Scene ビューで可聴範囲を確認**

1. `EmergencyBroadcastSpeaker` を選択
2. `Show Gizmos` が `true` になっていることを確認
3. Scene ビューで黄色のワイヤースフィアが表示される
4. この範囲内に避難者がいれば「聞こえる」

### **2. Console ログで確認**

避難者が放送を聞いた瞬間、以下のログが出力されます：

```
[Evacuee] Evacuee1(Clone): 行政無線の放送を聞きました - 津波警報が発表されました。海岸から離れて高台に避難してください。
```

### **3. LLM ログで確認**

`Logs/llm_decisions/*.txt` の `prompt:` セクションに、以下のように表示されます：

```
【防災行政無線の放送】
あなたは屋外スピーカーからの放送を聞きました:
津波警報が発表されました。海岸から離れて高台に避難してください。

※ この放送内容を踏まえて行動を判断してください。
```

## よくある質問

### **Q: スピーカーの位置はどうやって決めればいい？**

A: 実際の地図データや PLATEAU の建物データを参考にしてください。

- 市役所、学校、消防署などの公共施設の屋上や建物上部
- 実際の防災行政無線の設置場所があれば、それに合わせる

### **Q: 可聴範囲はどのくらいが適切？**

A: 一般的な屋外スピーカーの可聴範囲は：

- 小型スピーカー: 200-400m
- 中型スピーカー: 400-600m
- 大型スピーカー: 600-1000m

ただし、シミュレーションの目的に応じて調整してください。

### **Q: 複数のスピーカーが同じ内容を放送する場合、重複して聞いたことになる？**

A: 現在の実装では、**最新の放送内容で上書き**されます。
同じ内容を複数回聞いたことは記録されませんが、LLM の判断には「聞いた」という事実が反映されます。

### **Q: 放送タイミングをシナリオ（震度）に応じて変えたい**

A: 現在は固定時刻ですが、将来的には `AlertManager` にシナリオ連動のロジックを追加できます。
例: 震度7＋津波シナリオの場合、放送開始時刻を早める

## トラブルシューティング

### **放送が聞こえない**

1. `Audible Radius Meters` が適切か確認
2. 避難者の位置とスピーカーの位置の距離を確認
3. `Broadcast Start Time Seconds` が現在時刻より前か確認
4. `Broadcast Duration Seconds` が 0 でないか確認（0 の場合は1回だけ放送）

### **Gizmos が表示されない**

1. Scene ビューで `Gizmos` ボタンが有効になっているか確認
2. `Show Gizmos` が `true` になっているか確認
3. スピーカー GameObject が選択されているか確認

### **AlertManager が見つからない**

1. `EnvManager` が自動的に `AlertManager` を生成します
2. Hierarchy に `AlertManager` GameObject が存在するか確認
3. 存在しない場合は、シーンを再生すると自動生成されます

---

この設定により、避難者は実際の位置に基づいて「行政無線を聞いたかどうか」が判定され、LLM の判断に反映されます。
